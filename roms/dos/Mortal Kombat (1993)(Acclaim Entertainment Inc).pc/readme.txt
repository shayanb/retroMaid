--------------------MORTAL KOMBAT UPDATE 1/4/93-----------------------

This disk contains the patch for Mortal Kombat.  You must run the patch 
<MKFIX.EXE> from the directory which contains your MORTAL KOMBAT files.

For example, if the update disk is in your "B" drive and your MORTAL KOMBAT
files are in the "C:\KOMBAT" directory type:
1) CD C:\KOMBAT [Enter]
2) B:MKFIX [Enter]
